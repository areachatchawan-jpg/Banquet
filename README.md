# Banquet & Event — ระบบจัดการงานเลี้ยงและงานประชุม

ระบบภายในสำหรับ **Queensland Hotel Bangkok** และ **Baiyoke Sky Hotel**
ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ผ่านลิงก์เดียวกัน

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด |
| `config.js` | **ไฟล์เดียวที่ต้องแก้** — ใส่คีย์ Supabase |
| `supabase-setup.sql` | สร้างตารางและที่เก็บไฟล์ (รันครั้งเดียว) |
| `supabase-seed.sql` | นำเข้าข้อมูล 13 งานเดิม (รันครั้งเดียว) |
| `files/` | ไฟล์แนบเดิม 36 ไฟล์ (ผัง เมนู การ์ด ใบเสร็จ) |
| `supabase/functions/beo-read/` | ตัวอ่านใบ BEO จากรูปด้วย AI (ไม่บังคับ) |

---

## ติดตั้ง 4 ขั้น

### 1. สร้างฐานข้อมูล
Supabase → **SQL Editor** → **New query** → วางเนื้อหา `supabase-setup.sql` ทั้งหมด → **Run**

### 2. นำเข้าข้อมูลเดิม
ทำแบบเดียวกันกับ `supabase-seed.sql` → **Run**
ตรวจผล: `select count(*) from public.functions;` ต้องได้ **13**

### 3. ใส่คีย์
Supabase → **Project Settings** → **API** คัดลอก 2 ค่ามาใส่ใน `config.js`

```js
supabaseUrl:     "https://xxxxxxxx.supabase.co",
supabaseAnonKey: "eyJ...",
```

### 4. เปิด GitHub Pages
repo → **Settings** → **Pages** → Source: `Deploy from a branch` → Branch: `main` / `(root)` → **Save**

รอ 1–2 นาที ได้ลิงก์พร้อมใช้งาน

## ตั้งรหัสก่อนแจกลิงก์ (สำคัญ)

เปิดเว็บครั้งแรกจะเข้าเป็นแอดมินอัตโนมัติ → กด **⚙** → หมวด **ทั่วไป**

| ช่อง | ให้ใคร | ทำอะไรได้ |
|---|---|---|
| รหัสแอดมิน | ทีม Event | เพิ่ม/แก้/ลบงาน · ตั้งค่าระบบ · อ่าน BEO |
| รหัสพนักงานแผนก | ครัว ช่าง แบงเควท แม่บ้าน รปภ. | ดูงาน + ติ๊กงานเสร็จ |
| ไม่ใส่รหัส | ใครก็ได้ | ดูอย่างเดียว |

> รหัสนี้กันคนกดผิดได้ แต่ไม่ใช่ระบบความปลอดภัยจริง
> ใครที่เปิดดูโค้ดหน้าเว็บเป็นจะข้ามได้ ใช้กับทีมภายในเท่านั้น

## ตัวอ่าน BEO จากรูป (ไม่บังคับ)

ถ้าไม่ตั้งค่า ปุ่มนี้จะไม่ขึ้น ส่วนอื่นใช้ได้ครบ

1. Supabase → **Edge Functions** → Deploy ฟังก์ชันชื่อ `beo-read`
   วางโค้ดจาก `supabase/functions/beo-read/index.ts`
2. **Edge Functions → Secrets** เพิ่ม `ANTHROPIC_API_KEY` = คีย์จาก console.anthropic.com
3. คัดลอก URL ของฟังก์ชันไปใส่ `beoFunctionUrl` ใน `config.js`

ค่าใช้จ่ายประมาณใบละ 1–2 บาท

> ⚠️ ห้ามใส่คีย์ Anthropic ใน `config.js` เด็ดขาด — repo เป็น Public

---

## ข้อควรระวัง

- **repo เป็น Public** ข้อมูลลูกค้า (ชื่อ เบอร์ ทะเบียนรถ ยอดเงิน) อยู่ใน Supabase เท่านั้น ห้ามใส่ในไฟล์ที่ push
- `anon key` ออกแบบมาให้ฝังในหน้าเว็บได้ แต่ **`service_role` ห้ามเด็ดขาด**
- ตอนนี้ RLS เปิดให้ `anon` อ่าน-เขียนได้ทั้งหมด เหมาะกับใช้ภายในทีม
  ถ้าต้องการล็อกแน่นกว่านี้ ต้องเพิ่มระบบล็อกอินของ Supabase

## วิธีใช้งาน (ส่งให้ทีม)

1. เปิดลิงก์ → ใส่รหัสแผนก
2. กดแท็บ **แผนกของฉัน** → เลือกแผนกตัวเอง 1 ครั้ง ระบบจำให้
3. เห็นเฉพาะงานของแผนกตัวเอง ทำเสร็จข้อไหนกดติ๊ก
4. มือถือ: กดแชร์ → **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอนเปิดเหมือนแอป
